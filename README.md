## 운영 정보

- 주 배포: Netlify의 willowline 프로젝트, 정적 파일 수동 업로드
- GitHub 저장소: 소스 보관 및 이전 Pages 주소의 동일 콘텐츠 유지
- 분위기: 아이보리와 올리브 그린, 햇살과 잎 그림자
- 사진: 새로 생성한 브랜드 무드 이미지. 실제 매장·고객·시술 사진이 아닙니다.
- 실제 작업 사진과 후기 미제공으로 가짜 사례를 넣지 않고 공식 인스타그램으로 연결
- 샘플 원장의 해외 경력·사전 질문지·상담 및 시술 시간 등은 윌로우라인 정보로 차용하지 않음
- 가격: 자연눈썹 16만, 콤보 20만, 수지 19만, 헤어스트록 25만, 입술 28만 원
- 미확정 무료 리터치·할인·SMP·잔흔 제거는 노출하지 않음
- 네이버는 플레이스 이동, 실제 상담·예약 문의는 카카오톡 채널 연결
- 대표 검토 기간에는 noindex와 robots 차단 유지. 이는 접근 제한이 아니며 URL로 공개 열람 가능

## 수정 및 재배포

`index.html`의 문구·스타일·동작을 수정한 후 `index.html`, `hero.jpg`, `favicon.svg`, `robots.txt`를 ZIP 루트에 담아 Netlify 프로젝트의 수동 배포 영역에 업로드합니다. 별도 서버나 설치 과정 없이 동작합니다.
