# 윌로우라인 홈페이지 기획

따뜻한 아이보리와 올리브 그린, 자연스러운 눈썹 디자인을 중심으로 한 브랜드 홈페이지 제작안입니다.

[홈페이지 PRD 읽기](./PRD.md)

## 대표 검토 포인트

- 햇살·크림색·잎 그림자를 활용한 절제된 그린 방향
- 실제 사례를 먼저 보여주고 가격·상담·원장 이야기로 신뢰를 더하는 구성
- 남녀 모두 이용 가능하며 네이버 플레이스·카카오톡으로 연결
- 가격 포함 범위, 현재 주소, 메뉴 공개 범위는 정식 공개 전 확인

이 폴더는 PRD 문서 패키지입니다. 홈페이지 소스와 배포 완료 사이트는 아직 포함하지 않습니다.

권장 저장소 이름: `willowline`. 실제 GitHub 및 홈페이지 주소는 계정 연결과 게시 후 확정합니다.

GitHub 문서 공유 주소: https://github.com/dldpdls1020/willowline/blob/main/PRD.md

실제 홈페이지는 아직 구현·배포되지 않았습니다.
