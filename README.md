# 윌로우라인 · WILLOW LINE

따뜻한 자연광과 올리브 그린으로 구성한 반응형 브랜드 홈페이지입니다.

- 홈페이지 배포 주소: https://dldpdls1020.github.io/willowline/
- [홈페이지 PRD](./PRD.md)
- 호스팅: GitHub Pages, `main` 브랜치 루트

## 구현 내용

모바일 메뉴, FAQ 펼침, 시술별 가격, 원장 이야기, 위치·운영시간, 네이버 플레이스 및 카카오톡 상담 링크를 제공합니다. 모바일에는 하단 고정 상담 버튼이 있습니다.

실제 시술 사진과 후기 자료가 없어 가짜 갤러리를 만들지 않고 공식 인스타그램 작업 기록으로 연결했습니다. SMP·잔흔 제거·이벤트·무료 리터치·수상 상세는 확인 전 노출하지 않았습니다. 상세 조건과 실제 주소·예약 상태는 정식 운영 전 매장과 최종 대조해야 합니다.

대표 검토용이므로 검색 엔진에 `noindex,nofollow`와 `robots.txt`로 검색 제외를 요청합니다. 이 설정은 접근 제한이 아니며 URL을 아는 사람은 볼 수 있습니다.

## 파일

- `index.html`: 스타일과 메뉴 동작을 포함한 정적 홈페이지
- `hero.jpg`: AI로 새로 생성한 브랜드 무드 이미지. 실제 매장이나 시술 사진이 아닙니다.
- `favicon.svg`: 사이트용 선형 식물 심볼
- `robots.txt`: 대표 검토 기간의 검색 제외 요청
- `.nojekyll`: 별도 Jekyll 처리 없이 정적 파일 게시

외부 글꼴은 Google Fonts의 Noto Sans KR, Noto Serif KR, Cormorant Garamond를 사용하며 각 글꼴은 SIL Open Font License로 제공됩니다. 로컬 설치나 별도 빌드 없이 동작합니다.

## 검수

360·390·768·1440px에서 가로 넘침 없음, 주요 이미지 로드, 메뉴 열기 및 섹션 선택 후 닫기, FAQ 펼침을 확인했습니다. 예약 버튼은 외부 채널로 이동하며 이 사이트에서 예약을 확정하거나 고객 정보를 수집하지 않습니다. 네이버·카카오 외부 서비스에서의 실제 예약 완료는 별도 확인이 필요합니다.

## 정식 운영 전

실제 작업 사진·사용 동의, 후기 원문·인용 허락, 현재 주소·시간, 예약 메뉴, 리터치·추가금 조건, 공개 사업자 정보 등을 확인한 뒤 반영합니다. 정식 검색 노출 시 `noindex`와 robots 차단을 함께 해제합니다.
